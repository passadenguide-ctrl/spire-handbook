# Интерактивный Справочник: «Spire: The City Must Fall»

Современный, атмосферный веб-интерфейс и база знаний по настольной ролевой игре **«Spire: The City Must Fall»** на русском языке. Полностью оптимизирован для работы в РФ **без VPN**.

---

## 🌟 Возможности

1. **Базовые Классы (10 архетипов):**
   - *Азурит, Бунтарь, Вермиссийский Мудрец, Жрец Падали, Кумир, Лайян, Личина, Наделённый, Повитуха, Рыцарь*.
   - Иллюстрации в высоком разрешении, лор, флафф-цитаты, стартовые навыки и сферы, условия отдушины (Refresh) и интерактивное древо способностей (Core, Low, Medium, High).

2. **Дополнительные Продвижения (Extra Advances):**
   - *Министр Нашей Скрытой Госпожи, Городской Стражник, Призывник, Кровавая Ведьма, Пчеловод, Грангу, Друид-Экотеррорист*.
   - Четкие требования для вступления, особые отдушины и дары фракций.

3. **Районы и Сферы Шпиля (Districts & Domains):**
   - Вертикальный срез башни: от сияющего *Амаранта* вниз к некрополю *Новых Небес*, трущобам *Дереликтуса*, *Насесту*, *Вермиссиону* и *Сердцу*.
   - Фильтр по сферам влияния (Domains).
   - Встроенный плеер фонового саундтрека для каждой локации.

4. **Снаряжение, Оружие и Теги:**
   - Таблица урона и типов дистанций.
   - Интерактивные кликабельные теги свойств (*[Жестокое], [Пробивающее], [Скрытое], [Разрушительное]* и др.) со всплывающими подсказками.
   - Полный справочник свойств оружия и брони.

5. **Игровые Механики и Инструменты:**
   - **Дайс-роллер (d10 pool)** с автоматическим расчетом сложности, бонусов навыков, сфер и мастерства. Определение исхода (Крит. успех, Успех, Успех ценой, Провал, Крит. провал).
   - **Калькулятор стресса и Fallout**: проверка наступления последствий по броску d10 и полные таблицы Последствий (Кровь, Разум, Серебро, Тень, Репутация) для легких, средних и тяжелых степеней.

## ⚡ Автоматическое добавление новых классов и продвижений

В проекте реализован скрипт-наблюдатель. Вы просто кладете PDF или DOCX файл в папку, и он сам появляется на сайте:

```bash
# Запуск фонового наблюдателя
python scripts/watch_inbox.py
```

- Положите PDF нового класса в: `inbox/classes/`
- Положите PDF дополнительного продвижения в: `inbox/extra_advances/`

Скрипт автоматически извлечет арт обложки, распарсит текст, обновит базу данных, и страница в браузере обновится на лету!

## 🌐 Хостинг (Работает в РФ без VPN)

### Вариант 1: GitHub Pages (Основной)
В репозитории настроен `.github/workflows/deploy.yml`. При каждом `git push` в ветку `main` сайт автоматически собирается и деплоится на GitHub Pages.

### Вариант 2: Firebase Hosting
В репозитории подготовлен `firebase.json`. Для деплоя выполните:
```bash
firebase deploy
```
